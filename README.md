# 🛒 Amazon UI Clone  

A highly accurate **Amazon landing page clone** built using **HTML, CSS**, and a bit of **JavaScript** for smooth scrolling. It includes a **carousel** powered by [Flickity](https://flickity.metafizzy.co/) and a **sign-up form**.  

🚠 **Note:** This project is designed **only for PC screens** and is **not responsive** for mobile devices.  

## 🎯 Features  
👉 **Amazon-like UI** – Closely resembles the original landing page  
👉 **Flickity Carousel** – Smooth scrolling product slider  
👉 **Scroll to Top Button** – Easy navigation experience  
👉 **Sign-up Form** – Basic form with styling  

## 🛠️ Tech Stack  
- **HTML** – Structure of the page  
- **CSS** – Styling & layout  
- **JavaScript** – Scroll-to-top functionality  
- **Flickity** – For the interactive carousel  

## 🚀 Installation & Setup  
1. Clone the repository:  
   ```sh
   git clone https://github.com/your-username/amazon-ui-clone.git
   ```
